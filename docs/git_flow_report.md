# Git Flow Report

This document will contain evidence of the Git Flow process followed
during the development of this project.  Screenshots of `git log
--graph` will be included showing the `main`, `develop`, `feature/`,
`release/` and `hotfix/` branches.  Each commit message will be
professionally formatted according to the guidelines provided in the
project brief.

For the first commit the repository is initialised with the base
architecture and documentation.  Subsequent commits will be made on
feature branches to add missing functionality, respond to incidents
and harden the environment.
